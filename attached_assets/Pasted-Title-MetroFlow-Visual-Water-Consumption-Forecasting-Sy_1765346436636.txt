Title:
MetroFlow — Visual Water Consumption Forecasting System Using ML, Climate Indicators & Live Flow Levels (Flask)

Prompt:
Build a Flask-based visual forecasting system called MetroFlow that predicts city water consumption using historical data, climate indicators, and live water flow levels.
The system must focus on simple visual charts, easy-to-read values, and teacher-friendly UI without showing complex measurements like m³/s, RMSE units, or engineering terms.

✅ 1. Main Goal (Visual-Based System)
Create a dashboard that clearly shows:

A visual water consumption trend graph (line chart)

Climate indicators graphs (rainfall, humidity, temperature, wind, evaporation)

Live water flow widget

Shows only the number (e.g., "Flow Level: 18")

No units

Small 24-hour mini graph

Forecast charts for 24H, 7D, 30D

Clear blue (actual) vs. green (predicted)

Simple shaded future regions

Model comparison bar chart

Shows accuracy visually, not numeric units

Downloadable forecast CSV with simple values (no scientific units)

The dashboard must be simple, colorful, easy to understand by a college teacher.

✅ 2. Modules to Build
Create the following modules:

A. /modules/data_preprocessing.py
Load CSV

Handle missing values

Create lag features

Extract date: month, weekday, season

Merge climate indicators

B. /modules/live_water_flow.py
Generate simulated live flow level

No measurements → only a number

Create 24-hour trend for visualization

Create flow-level anomaly tag

C. /modules/feature_engineering.py
Normalization (MinMaxScaler)

Train-test split

LSTM sliding window

D. ML Models (/models/)
lstm_model.py

random_forest_model.py

xgboost_model.py

All must train and return predictions & accuracy.

E. /modules/forecasting_engine.py
Train all models

Generate visual-friendly outputs

Choose the best model

Return clean predictions
